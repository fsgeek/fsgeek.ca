# fsgeek.ca 

The function of this repo is to store the contents of my website in a clean persistent form.
It is constructed to make it easy for Generative AI to interact with it (or perhaps I should
say I hope it is constructed that way since it is empty as I write this file.)

The first phase is to migrate from WordPress ('nuff said - it's a classic example of modern
tech destruction of utility in favor of monetization.)

The second phase is to make it easy for the putative owner to add new content to the site
mostly in the form of a blog.
